# Recette de la consolidation

Environ 30 minutes, dans Electron, sur le Lab. Ferme le Studio installé, démarre Docker, puis dans `studio-ux` : `npm run studio:lab`.

Au premier lancement, le Lab a son propre dossier : tes favoris y repartent de zéro.

1. **Médias.** Alertes → Réglages → Médias : 0 sur 29, les emplacements et leurs fichiers. Clique « Importer les 28 fichiers trouvés », puis
   « Importer » sur « Copie du Studio installé » pour `Raid Titan.webm`. Attendu : 29 sur 29, tes originaux intacts. Puis Effets → « Importer ce qui manque ».
2. **TTS.** Écris un message. « Écouter » ne touche pas la file. Choisis Luna_lab, clique « Simuler l’achat » : le lecteur Studio s'ouvre seul,
   le message passe en file puis se lit, le solde baisse. Enchaîne deux viewers. Teste Passer, Passer et rembourser, le détail. Si elle n'a pas assez, « +50 000 ».
3. **Tombola.** Une manche complète.
4. **Alertes.** Aperçu, timeline, puis Simulation → Follow : l'alerte arrive dans la file.
5. **Spotify.** Passe à Ouvert. Essaie Numb, Trop long, Introuvable, Lien refusé. Choisis Modo Lab et clique `!songskip`. Coupe l'appareil, déclenche 429.
6. **Récompenses.** « Charger le catalogue fictif », puis Tester sur Crédit TTS et sur Scène pause (échec attendu : OBS fictif non connecté).
7. **Équipe.** Modération → Équipe : les rôles, « Qui peut faire quoi », « Dans le chat ». Dis-moi si ta modératrice a le badge **Lead Moderator**.
8. **Laboratoire et Simulation.** Live fictif, événements, simulateurs. Mini-jeux : ouvre-les depuis leur page.
9. **Reste du Studio.** Système, Activité, Communauté, Modules, à 1024 × 768 aussi.

Rien de tout ça ne parle à Twitch, OBS, Spotify ni StreamElements réels. Parité complète : [PARITE.md](PARITE.md). Diagnostics : [CONSOLIDATION.md](CONSOLIDATION.md).
