# Inventaire des modules : où est le code

Relevé du **10/11/2026** sur `origin/main` `afe98cf`, en lecture seule. Ce document dit **où** vit chaque module, ce qui
l'allume, ses commandes et ses tests.

- **L'état** de chaque module (livré, à valider…) n'est **que** dans [ROADMAP.md](ROADMAP.md) § 1.
- **Les versions** sont dans [PROJECT_STATUS.md](PROJECT_STATUS.md) § 3.
- Pour un module précis, lire ensuite son document.

Abréviations : **C** = `apps/core-api/src` · **S** = `apps/studio/server/src` · **W** = `apps/studio/web/src/pages` ·
**D** = `apps/studio/desktop/src` · **X** = `apps/twitch-extension/extension` · **B** = `apps/twitch-bot/src` · **P** =
`packages/schemas/src` · migrations dans `supabase/migrations` (99 fichiers, jumeaux `_lab` pour le Lab, listes dans
`C/db/migration-scopes.ts`).

Points d'assemblage communs :

- `C/app.ts` (`createCore()`) ;
- socle de modules `C/modules/host.ts`, liste `C/modules/index.ts` ;
- routeur du chat `C/lab-chat/games.ts` ;
- mots réservés `C/commands/reserved.ts` ;
- réglages de module `C/module-settings/service.ts` ;
- règle « payant seulement en live » `C/stream/live-gate.ts`.
