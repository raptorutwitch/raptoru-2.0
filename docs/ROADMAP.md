# Roadmap Raptoru 2.0

Roadmap unique, consolidée le **24/10/2026** à partir de tous les documents d'état (sources en bas). Aucune priorité
n'est inventée ici : une priorité n'apparaît que si un document l'a enregistrée ; les désaccords entre documents sont
listés comme **arbitrages** à faire par Antoni. État courant, versions et prochaine action : [REPRISE.md](REPRISE.md).

**Objectif** : tout le stream piloté depuis Raptoru Studio, sans SAMMI (abandonné), avec le Core comme seule vérité.
**Phase actuelle** : Production en service depuis la bascule du 20/10 ; stabilisation + reprise des fonctions
manquantes, module par module.

## Échelle d'état

1 Développé · 2 Testé en Lab · 3 Déployé en Production · 4 Validé en réel par Antoni · 5 Terminé et clôturé.
« Validé » = testé à la main par Antoni ; des tests automatiques ne valident rien. **NV** = non vérifiable depuis le
dépôt ou les documents.
