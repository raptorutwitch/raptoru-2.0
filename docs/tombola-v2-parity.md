# Tombola V2 — matrice de parité prototype → produit

Spécification : `prototypes/tombola-v2/` (validée par Antoni comme spécification produit / UX / DA ; local, non
versionné). Variantes retenues : overlay **C4** (ouverture), **G** (reveal normal / SUPER / giveaway), **roulette
compacte** (FULL OSEILLE), annulation, FIFO ; ancrage overlay **56 px haut / 56 px droite** pour toutes les phases.
Extension : héros anneau, gabarit centré (aucune Tombola / FULL / annulée). Studio : `studio.html`.

Décisions d'Antoni (01/10/2026) : D1 registre de monnaies Lab générique · D2 simulateur de chat + ingestion
Twitch réelle derrière un interrupteur OFF · D3 cagnotte ~78 / 18 / 4 % · D4 gagnants auto · D5 phases Core,
reveal viewer = type + nombre de gagnants + marge · D6 SUPER 1/400 · D7 permissions (« Gérer la Tombola ») ·
D8 vraie pause Core, visuel minimal · D9 vraie session de stream · D10 `!annuletombola` · D11 pas d'anciennes
variantes ni x1/x4 · D12 UI minimale pour participants / durées / fiche manche. Phase C : supermod = accès
complet (configuration comprise) ; pas de nouvelle manche pendant l'affichage d'un résultat ; ajout manuel
au-dessus d'une pause, jamais au-dessus d'un blocage individuel sans `force` audité. Ajout : planificateur
automatique + son de lancement (avant la phase D).

Légende : **C** Core · **S** Studio · **E** Extension · **O** Overlay · **B** chat · **M** console Modération.
« Core ✓ » = implémenté + tests automatiques (phase C). Rien n'est « validé » tant qu'Antoni ne l'a pas testé.
