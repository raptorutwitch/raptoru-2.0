## 2. Ce qui s'est passé le 10/11

1. **Mise à jour OBS 32.2.2 → 33.0.1** (par Antoni). OBS 33 a retiré des fonctions graphiques dont dépendaient les
   plugins compilés pour OBS 32. Quatre d'entre eux étaient ignorés (« Module … not loaded ») :
   - obs-shaderfilter, qui porte les filtres Chaos, FX Cam et Votekick ;
   - Composite Blur ;
   - Advanced Masks, qui porte le masque de la cam ;
   - Image Reaction.

   Les 16 filtres concernés étaient restés dans la collection avec leurs réglages.

2. **Réparation** : les versions officielles stables compatibles OBS 33 ont été installées depuis les dépôts GitHub des
   auteurs, avec le même identifiant de filtre et les mêmes clés de réglage. Résultat : 0 « not loaded » et aucun
   filtre manquant.
3. **SE.Live désactivé** (à la demande d'Antoni) : depuis OBS 33, la fermeture d'OBS s'arrêtait dans
   `obs-streamelements-core`, et une alerte de crash apparaissait à chaque démarrage. Depuis la désactivation, OBS se
   ferme en 4 s, avec un journal complet, et démarre sans alerte.
   - La dernière version **stable** de SE.Live (26.9.4) vise OBS 32.2 ; seules des versions **alpha** ciblaient
     OBS 33.0.1 le 10/11.
4. Retour d'Antoni (non vérifié par un agent) : Bonk et TTS fonctionnent de nouveau. Studio est reconnecté au
   WebSocket (vérifié : client local connecté dans le journal).
